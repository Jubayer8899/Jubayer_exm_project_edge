# Exam Results Visualization

This project is made using Python to visualize student exam scores from a CSV file.

## Features
- Read CSV data using Pandas
- Create bar charts using Matplotlib
- Simple and beginner-friendly project
- Save chart as PNG image

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Project Structure

Exam Results/
│
├── source/
│   └── exam_1.py
│
├── data/
│   └── exam_data.csv
│
├── output/
│   └── bar_chart.png
│
└── README.md

## How to Run

1. Install libraries:

pip install pandas matplotlib seaborn

2. Run the project:

python exam_1.py

## Output
The program generates a bar chart showing students' math scores.

## Purpose
This project was created for learning Python data visualization and plotting techniques.
